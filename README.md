## 🚀 The Eazi Profit Product Ecosystem
Our flagship suite splits critical petrochemical and custody transfer workflows into targeted, single-responsibility toolboxes that run **100% offline** on the field with zero network dependency.

### 🟢 1. API Density Core Engine
Features an automated, non-linear 4-pass iterative convergence algorithm that computes standard API @ 60°F and SG 60/60°F from direct hydrometer inputs or raw lab-balance pycnometer weights.
👉 **[Launch Live API Core App](https://ci-arts.github.io/eazi-api-calc/)**

### 🔵 2. Centrifuge BS&W Volume Suite
Automates volumetric sediment deductions compliant with laboratory centrifuge standards. Enter dual-tube graduated cone readings, gross dipped barrels, and sample variables for automated VCF, GSV, and Net Standard Volume (NSV) ledgers.
👉 **[Launch Live BS&W Core App](https://ci-arts.github.io/eazi-bsw-suite/)**

### ⚓ 3. Marine Cargo Logistics Matrix
Built to precisely match field terminal ullage report sequences. Automatically isolates Gross Observed Volume (GOV) from Total Observed Volume (TOV), adjusts for VCF (Table 5A), integrates fault-tolerant dry-tank logic, and outputs definitive Bill of Lading (B/L) metrics.
👉 **[Launch Live Marine Cargo App](https://ci-arts.github.io/eazi-marine-cargo/)**

### 📊 4. OPEC Compliance & Allocation Tracker
An executive auditing dashboard that evaluates a facility's daily net standard production run against assigned corporate daily OPEC allocation quotas, computing live consumption metrics and safety margins.
👉 **[Launch Live OPEC Tracker App](https://ci-arts.github.io/eazi-opec-tracker/)**
